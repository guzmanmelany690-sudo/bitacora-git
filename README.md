\# bitacora-git



Proyecto de práctica para registrar los conocimientos adquiridos sobre el uso de Git y la sincronización con repositorios remotos en GitHub.



\## Contenido



\- `bitacora.md`: contiene apuntes sobre los comandos remote, push, fetch y pull.

\- `.gitignore`: excluye los archivos `.env` y aquellos que tienen extensión `.log`.
