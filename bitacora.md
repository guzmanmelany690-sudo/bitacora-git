\# Bitácora de Git



\## Trabajo con repositorios remotos



Un repositorio remoto permite compartir el proyecto y sincronizar los cambios con otros repositorios, como GitHub.



\## Comandos practicados



\- `git remote add origin URL`: vincula el repositorio local con un repositorio remoto.

\- `git push -u origin main`: envía los commits de la rama main al repositorio remoto y establece su seguimiento.

\- `git fetch origin`: descarga información y cambios del repositorio remoto sin modificar la rama local.

\- `git pull --no-edit`: integra los cambios del repositorio remoto en la rama local sin abrir el editor para el mensaje de merge.



\## Conclusión



Estos comandos permiten mantener sincronizado el trabajo local con GitHub y gestionar los cambios de manera ordenada.
